# Merlijn Schimmel — Me as a Brand
A responsive static website. No installation, dependencies, tracking or backend required.

## Preview
Open index.html in a browser (keep style.css and script.js in the same folder).

## Publish with GitHub and Vercel
1. Create a GitHub repository (private if preferred).
2. Upload index.html, style.css and script.js to the repository root and commit.
3. In Vercel, select Add New > Project and import the repository.
4. Select the Other framework preset if necessary. Leave build command and output directory at their defaults for a static site. Deploy.
5. Open the resulting Vercel URL and check the site before submitting it on Canvas.

The site discusses personal information including visual impairment and future family goals. Review the text before publishing publicly. A private repository alone does not make a Vercel deployment private.

Use the Print / save PDF button at the bottom if a backup submission is needed. The target audience panels are expanded in print.
